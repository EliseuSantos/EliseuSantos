### Hi, I'm Eliseu

I'm a Tech Lead at **JetSales**, a B2B customer service platform where WhatsApp is the main channel. I joined in April 2025 as a senior engineer and have led the engineering team since November 2025. Before that I worked on the frontend platform at **will bank** and on investment products at **PagBank**. I've been writing software since 2012, from Aracaju, Brazil.

Most of my work now is getting AI to run in production:

- the product's agent layer: what the agent knows, what it can resolve on its own and when it hands the conversation to a person;
- an MCP gateway in Go that gives agents controlled access to engineering tools, with an agent on top that turns an issue into a pull request;
- a knowledge base that the team and the agents can query in plain language.

I write about this (in Portuguese) at [eliseu.dev](https://eliseu.dev).
